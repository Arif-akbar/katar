# Changelog

Semua perubahan penting pada proyek ini akan didokumentasikan di file ini.

## [2.0.0] - 2026-05-29

### ✨ Added (Fitur Baru)
- **Announcement Bar**: Banner pengumuman yang dapat ditutup di bagian atas
- **Bottom Navigation**: Navigasi mobile khusus di bagian bawah (5 menu utama)
- **Back to Top Button**: Tombol scroll ke atas yang muncul saat scroll
- **Scroll Reveal Animation**: Animasi fade-in saat elemen masuk viewport
- **Gallery View Toggle**: Switch antara tampilan grid dan list
- **Active Section Detection**: Navbar otomatis highlight section yang aktif
- **Keyboard Shortcuts**: ESC untuk menutup modal
- **Improved Modal System**: Body overflow handling untuk mencegah scroll

### 🎨 Changed (Perubahan)
- **Theme Redesign**: Dari blue theme ke earth tone (hijau & krem)
- **Typography**: Ganti font ke Plus Jakarta Sans & Fraunces
- **Hero Section**: Redesign dengan pattern background dan badge
- **Card Design**: Accent bar dan emoji yang lebih modern
- **Button Styles**: Lebih rounded dan dengan icon
- **Pengurus Cards**: Avatar design dengan role badge berwarna
- **Gallery System**: Improved dengan better UX

### 🔧 Fixed (Perbaikan)
- **JavaScript Compatibility**: Sinkronisasi penuh dengan HTML baru
- **Responsive Issues**: Perbaikan layout di berbagai ukuran layar
- **Modal Closing**: Konsisten dengan ESC dan click outside
- **Navbar Scroll**: Smooth transition saat shrink
- **Gallery Toggle**: Logika show/hide yang lebih reliable

### 🚀 Improved (Peningkatan)
- **Performance**: Optimasi dengan passive event listeners
- **Accessibility**: ARIA labels, roles, dan keyboard navigation
- **Code Quality**: Cleaner code structure dan comments
- **Error Handling**: Better null checks dan fallbacks
- **Mobile Experience**: Touch-friendly dan optimized layout

### 📝 Documentation
- **README.md**: Dokumentasi lengkap dengan panduan penggunaan
- **CHANGELOG.md**: File ini untuk tracking perubahan
- **Code Comments**: Komentar yang lebih jelas di semua file
